# 📚 Session Analytics Dashboard

An interactive machine learning dashboard built with Streamlit and Random Forest Classifier to analyze educational session data and predict whether a session will be used again.

## 🚀 Features

- **📑 Dataset Overview:** Interactive table and target class distribution charts.
- **📊 Model Insights:** Real-time accuracy metrics, classification reports, and confusion matrix.
- **📈 Feature Importance:** Visual breakdown of the most influential factors.
- **📦 Advanced Analytics:** Cross-tabulations, satisfaction rating trends, and session duration insights.
- **🔮 Outcome Prediction:** Interactive form to predict the `UsedAgain` probability for custom input sessions.

## 🛠️ Tech Stack

- **Frontend & App:** Streamlit
- **Machine Learning:** Scikit-Learn (Random Forest)
- **Data Manipulation:** Pandas, NumPy
